# Klik — Standalone iOS Project

SwiftUI iOS app with a full-screen camera as the main screen.

## Open in Xcode

Open `Klik.xcodeproj` in Xcode 15+ on a Mac, then run on a physical iPhone.

## Push to GitHub (repo: `klik`)

1. Create an empty repo on GitHub named **klik** under your account.
2. Run:

```bash
cd klik
git remote add origin https://github.com/MurtuzaQuantumCoder/klik.git
git push -u origin main
```

This folder is its own Git repository, separate from `ai-pedestrian-signal-optimisation`.
